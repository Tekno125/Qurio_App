PENTING — KONSISTENSI NAMA PESERTA:
═══════════════════════════════════════════════
Setiap siswa punya SATU nama tetap dari daftar 30 siswa.
Kalau "Budi Santoso" hadir di 5 sesi berbeda, isi `participants.name`
= "Budi Santoso" (persis) di KELIMA sesi tersebut.
Ini penting karena analytics pakai nama sebagai identity key.

JANGAN random nama per sesi. Pakai pool 30 nama yang sudah dibuat.

DATA PER SESI:

A. Polls KUIS (untuk skor siswa):
   - Setiap sesi punya 5 poll type='quiz'.
   - Setiap poll = 1 soal + 4 poll_options (1 correct).
   - Pertanyaan sesuai tema sesi.
   - Semua poll status='published'.
   - INI YANG PALING PENTING untuk analytics.

B. Polls Q&A:
   - Setiap sesi punya 1 poll type='qa'.
   - Isi `questions`: 5-15 pertanyaan per sesi, kolom `text` diisi
     pertanyaan realistis, `student_id` NULL (karena anonymous),
     `participant_id` diisi dari participants sesi itu,
     `upvotes` random 0-20, `answered` random 30%.

C. Polls WORDCLOUD:
   - Setiap sesi punya 1 poll type='wordcloud'.
   - Isi `wordcloud_word_counts`: 40-80 kata distribusi Zipf.

D. Participants (WAJIB lengkap):
   - Setiap sesi: 20-28 baris `participants`.
   - Pilih random dari pool 30 siswa.
   - `name` = nama persis dari pool (jangan diubah).
   - `absen` 2 digit ('01', '02', dst). Untuk siswa yang sama,
     usahakan absen konsisten lintas-sesi.

E. Responses KUIS:
   - Untuk setiap poll quiz di setiap sesi:
     - 70-90% dari participants sesi itu hadir menjawab.
     - Untuk setiap jawaban:
       - `participant_id` = peserta yang jawab
       - `student_id` = NULL (karena anonymous)
       - `option_id` = pilih random dari 4 opsi
       - `is_correct` = (option_id === opsi yang is_correct)
     - Distribusi nilai NORMAL (Box-Muller), μ=75, σ=12, clamp 0-100.
   - 1-2 soal per sesi dibuat "SULIT": 60-80% siswa di-set
     is_correct=false.
   - `submitted_at` disebar dalam rentang sesi berjalan.

F. Responses Q&A & Wordcloud:

   - Wordcloud: 60-80% isi response 1 kata acak.

BAGIAN D — ENDPOINT ANALYTICS
═══════════════════════════════════════════════════════════════════

Buat `backend/src/routes/analytics.route.js` dan
`backend/src/controllers/analytics.controller.js`.

Semua endpoint di-protect `teacherLimit`. Filter hanya sesi milik
guru yang login (`WHERE sessions.teacher_id = $1`).

IDENTITY KEY LINTAS-SESI = `LOWER(TRIM(COALESCE(users.name,
participants.name)))`.

1. GET `/api/analytics/summary?period=7d|30d|all`
   Return:
   {
     totalStudents: number,       // COUNT DISTINCT nama siswa
     averageScore: number,        // rata-rata skor semua kuis 0-100
     participationRate: number,   // persen
     totalSessions: number
   }

2. GET `/api/analytics/scores?period=7d|30d|all`
   Return array skor per siswa per sesi:
   [
     {
       studentKey,        // lowercase name untuk grouping
       studentName,       // display name
       sessionId, sessionTitle,
       score, correctCount, totalQuestions,
       submittedAt
     }, ...
   ]
   Query: JOIN responses + poll_options + polls + sessions
          LEFT JOIN participants, LEFT JOIN users.
   Filter: poll.type='quiz', is_correct IS NOT NULL.

3. GET `/api/analytics/students?period=7d|30d|all`
   Return array partisipasi per siswa (grouped by nama):
   [
     {
       studentKey,
       studentName,
       sessionsJoined,      // COUNT DISTINCT session_id
       questionsAsked,      // COUNT dari questions
       responsesSubmitted   // COUNT dari responses
     }, ...
   ]
   JANGAN hitung upvote.

4. GET `/api/analytics/topics?period=7d|30d|all&limit=5`
   Return topik tersulit:
   [
     {
       questionId, questionText, sessionTitle,
       incorrectRate,     // persen
       totalAnswers
     }, ...
   ]
   Filter poll.type='quiz', totalAnswers >= 5. Urutkan DESC.

5. GET `/api/analytics/participation-trend?period=7d|14d|30d`
   Return titik harian:
   [{ date, label, participants }, ...]
   Isi hari kosong dengan 0.

ATURAN SQL:
- Parameterized ($1, $2). Jangan string concat.
- Hindari N+1.
- GROUP BY LOWER(TRIM(...)) untuk identity.

Daftarkan di `backend/server.js`:
`app.use("/api/analytics", analyticsRoutes);`
