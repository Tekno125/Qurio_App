─────────────────────────────────────────
F.5.1 — MIGRATION DATABASE
─────────────────────────────────────────

Buat file: `backend/src/config/db/migrations/002_add_class_size.sql`

```sql
-- Jumlah siswa di kelas saat sesi dibuat. NULL = guru tidak mengisi.
ALTER TABLE sessions
  ADD COLUMN IF NOT EXISTS class_size INT NULL
  CHECK (class_size IS NULL OR class_size BETWEEN 1 AND 500);

COMMENT ON COLUMN sessions.class_size IS
  'Jumlah siswa di kelas saat sesi dibuat. NULL jika tidak diisi.';
```

Buat script runner `backend/scripts/run-migration.js`:
- Baca file `.sql` di `backend/src/config/db/migrations/` urut alfabet.
- Track di tabel `_migrations` (filename, executed_at).
- Skip yang sudah dijalankan, jalankan yang baru.
- Print progress.

Test: `node backend/scripts/run-migration.js`

F.5.2 — BACKEND: TERIMA class_size
─────────────────────────────────────────

Update `backend/src/controllers/sessions.controller.js`:

1. `createSession`: terima `class_size` dari body.

   - Simpan NULL kalau kosong.

2. `getSessions` (list): kembalikan `class_size` di response.

3. `getSession` (detail): kembalikan `class_size`.

4. `updateSession`: allow update `class_size`.

3. Update `createSession()` di `frontend/lib/api.tsx`:

Update `getAnalyticsSummary` di `analytics.controller.js`:

2. Update response:

     "participationRate": 100,

BAGIAN G — RECHARTS LEBIH RAME TAPI EFEKTIF
═══════════════════════════════════════════════════════════════════

1. **Tren Partisipasi — AreaChart dengan gradient**

   Contoh di kartu "Tingkat Kehadiran".
